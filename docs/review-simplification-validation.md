## 初始失败与处理

- 规划阶段首次 Python 启动受沙箱限制，报 `uv trampoline failed to spawn Python child process`、`permission denied (os error 5)`；使用同一现有环境按普通用户权限重跑后通过，未改 ACL、环境或依赖。这是启动失败，不是测试结论。
- 首次桌面捕获因活动标签已切到其他视图而以 `unexpected active file` 停止，未执行产品断言；重新选择唯一的合成测试标签后六个场景通过。探索时 `base:query` 没有返回标准输出，未据此判定结果为空，验收采用实际可见 DOM。初始情况与最终结果一并保留在桌面证据中。
- 复核发现 frontmatter 专用加载器会额外限制插件扩展映射的键名，因此 Base 改用标准安全 YAML 加载，仅保留计划要求的外层检查；对应扩展数据用例已通过。
